## 二、项目介绍文案（GitHub / 技术社区 / 开发者群）

### 短版（三句话）

**Burger Quest · 麦门异世界** 是一个基于麦当劳中国官方 MCP Server 的游戏化点餐规划 Skill：用一句话描述预算、口味、人数和用餐方式，它通过官方 MCP 查询真实门店/菜单/优惠/营养，经 `calculate-price` 权威核验价格，给出最多三个可比较的点餐方案和一张复古 RPG 成就卡。它的核心铁律是**不编造商品、不编造价格、不编造优惠**——查不到就说查不到，算不出就诚实失败。纯规则式中文解析（无大模型依赖）、257 个测试、CI 全绿。

### 中版（技术社区发布用）

**把「今天吃什么」变成一次有数据兜底的 RPG 冒险。**

Burger Quest（麦门异世界）是「麦当劳程序员创意开发大赛」参赛作品，一个独立开发的非官方项目。它解决一个具体问题：面对几百个 SKU 和复杂优惠规则，用户很难在预算内做出不后悔的点餐决策。

**它怎么工作：**

1. **规则式中文解析**：从「预算 35，想吃辣，两个人，希望尽量高蛋白，不想点太多饮料」中提取约束——支持模糊预算（二三十元按上限处理）、否定口味（不吃辣是硬约束）、营养偏好（低卡/高蛋白，且明示非医疗建议），区分「用户明确限制」与「系统推断的软偏好」；
2. **官方 MCP 四段式数据链**：`query-meals` 取菜单骨架 → 一次 `calculate-price` 探测同时拿到餐品名称与真实单价（详情仅作回退）→ 优惠券试探（最优单券→双券，是否可叠加由官方核验决定，不默认叠加）→ 组合验价得到权威应付总价；
3. **诚实性设计**：总价只认 `calculate-price` 返回；营养数据缺失显示「未知」而非装饰数字；查询失败明确告知；真实模式失败绝不静默降级到演示数据；MVP 不接入任何写操作（下单/领券/积分）；
4. **可靠性**：分工具超时、有限退避重试（401 不重试/429 降速）、任务内去重与短 TTL 缓存、全链路调用审计（序号/耗时/用途/成功状态）；
5. **工程化**：257 个自动化测试覆盖解析/规划/安全/边界/MCP 故障路径；GitHub Actions 在 Python 3.10–3.13 矩阵上运行；演示数据随 wheel 分发，`pip install` 后离线演示开箱即用。

**快速体验（离线，无需 Token）：**

```bash
pip install -e ".[dev]"
python -m burger_quest demo "我想吃辣，预算35，外送到南山科技园，一个人"
```

真实模式需要到 https://open.mcd.cn/mcp 申请 MCP Token 并配置到 WorkBuddy 连接器（或 `MCD_MCP_TOKEN` 环境变量）。作为 WorkBuddy Skill 使用时，仓库 `SKILL.md` 指导 AI 按同一调用链编排官方连接器。

**边界（透明声明）**：MVP 不自动下单；真实数据依赖 MCP 服务可用性（限流 600 次/分钟）；港澳台不在服务范围；优惠券字段已验证范围有限（依赖账户状态）。
